## 확인 범위

이 문서는 영상의 한국어 자동 자막을 바탕으로 시연 순서와 캡처 후보를 정리했습니다. 자동 자막의 명백한 오기는 문맥에 맞게 정리했으며, 불명확한 수치나 인명은 옮기지 않았습니다.

현재 브라우저에서 영상 화면이 00:00의 로딩 상태에 머물러 실제 프레임은 확인하지 못했습니다. **아래 시간은 장면을 찾기 위한 구간이며, 시각적으로 검수한 캡처 시점이 아닙니다.** 새 스크린샷과 GIF는 아직 추출하지 않았습니다. 기존 이미지와 GIF는 README의 '이전 UI 참고 화면'에 보존했습니다.

README에는 서비스 순서대로 1–5번을 배치합니다. 개인 기여를 설명할 때는 **2번 부품 관계 그래프**와 **5번 관리자 상담**을 우선 제시합니다.

그래프 장면은 부품 관계 그래프 자체가 보이는 프레임을 선택해야 합니다. 견적서의 slotboard 화면만으로 개인 그래프 기여를 설명하지 않습니다.

## 영상 기준 전체 서비스 흐름

### A. PC 견적과 구매 단계

| 영상 구간 | 사용자 행동 | 발표에서 설명한 결과 |
| --- | --- | --- |
| 00:58–01:29 | 메인 화면에서 게임 용도의 PC 견적 요청, 예산 질문에 응답 | AI 검색·상담이 목적과 예산을 구체화 |
| 01:29–01:41 | 추천 견적 3개 중 균형형 선택 | 호환성 검사를 통과한 구성 확인 |
| 01:41–02:14 | 더 부드러운 게임 화면을 요청 | GPU 개선안 적용, 성능·가격 변화와 변경 이력 비교 |
| 02:14–02:37 | 원하는 케이스로 수동 변경 | 호환 경고 발생, 체크리스트와 부품 관계 그래프로 원인 확인 |
| 02:37–03:07 | 호환되는 케이스 요청·선택, 완성 견적 저장 | 대체 후보 적용 후 내 견적함으로 이동 |
| 03:07–03:24 | 기존 견적과 새 견적 비교 | 종합 점수·성능 및 부품 차이를 확인하고 선택 |
| 03:24–03:44 | 기사 제안 요청과 기사 선택 | 제안·입찰과 기사 평가 정보를 바탕으로 매칭 |
| 03:44–04:04 | 결제 단계 진행 | 사전 준비한 포인트로 결제 시연 후 최종 확인 화면 표시 |

발표자는 03:49–03:58에 실제 결제가 아닌 포인트 시연이라고 설명합니다. 포트폴리오에서도 실제 상용 결제가 운영되는 것으로 표현하지 않습니다.
